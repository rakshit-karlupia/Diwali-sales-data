# Diwali-sales-data
Diwali Sales Data Analysis 🪔📊  A Data Analytics project focused on analyzing Diwali sales data to uncover customer purchasing patterns, top-performing products, customer demographics, and key business insights.


🔍 Key Analysis
Cleaned and preprocessed Diwali sales data using Python & Pandas
Performed Exploratory Data Analysis (EDA)
Analyzed customer demographics such as age, gender, occupation, and marital status
Identified top-selling products and product categories
Analyzed sales patterns across states, occupations, and customer segments
Created visualizations using Matplotlib and Seaborn
Derived actionable insights to understand customer behavior and improve sales strategies


🛠️ Technologies Used
Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook
